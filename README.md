# Online Voting System

A Java-based Online Voting System developed as an academic project to demonstrate Object-Oriented Programming (OOP) concepts.

## Project Overview

This project is a demo voting system where voters can be registered, candidates can be added, and registered voters can cast their votes during a specified election period.

The current version uses fictional voters and candidates for demonstration purposes.

## Features

- Voter registration
- Candidate registration
- Voter authentication
- Vote casting
- Prevention of duplicate voting
- Election time validation
- Vote counting
- Display of election results
- Export of results to a text file
